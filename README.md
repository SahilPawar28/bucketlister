# BucketLister 🗺️

Pin your travel dreams on a map, organize them by category, track which ones you've visited, and share curated maps with friends.

## Features

- Pin places on an interactive map with category tags (Adventure, Food, Solo, Romantic, Culture, Family)
- Mark places as visited and filter by category/status
- List view of all pinned places
- Share maps publicly or via a private link
- Google/email authentication via Firebase

## Stack

- React + Vite
- Leaflet + Mapbox (custom-styled raster tiles)
- Firebase (Auth + Firestore)
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
